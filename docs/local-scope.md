# Historical initial local candidate scope

This note preserves the initial environment observations on November 1. It is historical evidence, not a description of current implementation or delivery status. Read `reports/verification/delivery.json`, `reports/checklist.json` and `docs/operator.md` for the current state.

The initial execution environment had Node 24.19.0 and bundled SQLite 3.53.3. GitHub CLI had no authenticated host. The package registry DNS probe failed with No such host is known. Required packages were absent from the npm cache and a local inference service was unavailable. Connected Neon and Vercel account listing succeeded, but those listings did not establish direct TLS, free-host eligibility or container deployment. The initial candidate used native JavaScript modules and SQLite to exercise contracts while the TypeScript, pg, eve and hosted Postgres target remained incomplete.

Later verified execution installed the exact locked dependencies, exercised direct TLS Postgres, ran the actual CPU model and completed independent recovery and clean worktree checks. The actual model produced zero supported proposals and failed its useful-model criterion. Its results remain separate from the deterministic baseline. On November 2 the approved Vercel Production credential transfer and container deployment succeeded, followed by three public GET health and origin checks and nine browser checks of the API-hosted interface. That interface serves native modules; it is not a compiled Pages deployment.

On November 3 the public repository, compiled Pages deployment and manual collection dispatch were verified at revision `05ec1ac5044a84e8f52796fad26275157a9fc01d`. The latest public GET checks passed four cases, including matching API and Pages build metadata. The separate Pages browser flow passed nine checks in `reports/browser/pages.json`, including recovery of the same receipt and a separate client observing exactly one receipt. Independent Postgres assertions confirmed eight HTTP attempts and four partial captures from the Actions runner without advancing usable comparison heads. The UTC schedule is enabled, but no scheduled run has been observed. Public release retains its separate evidence requirement.
