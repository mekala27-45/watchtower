# Limits

## What this system can support

Typed metadata differences between identified captured revisions. Explicit coverage for a bounded procedure. Independently graded synthetic temporal events. Recovery of one internal publication effect under a stable key in the tested local database. Contract-level validation of the three permitted agent tools.

## What this system cannot support

Complete release history. Deletion from an absent list entry or one unavailable request. Security, compatibility or upgrade recommendations. General model accuracy from a small synthetic subset. Exactly once delivery to arbitrary external services. Exact schedule timing. Actual agent quality or public readiness without the missing executions.

## Unchanged versus unknown

In the valid and invalid conditional-response family, a response without a matching cache cannot establish the prior content. Treating that response as an empty list would erase the comparison baseline and make a failed collection look quiet. The collector attempts one unconditional recovery within budget, then retains unknown when recovery fails. The cache and head-preservation tests protect that choice.
