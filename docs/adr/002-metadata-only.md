# Metadata-only evidence

Decision: Retain factual fields and note digests while discarding note prose and personal fields.

Source or experiment: GitHub releases documentation and normalizer tests.

Rejected alternative: Semantic summaries from release titles would claim meaning that the evidence does not support.

Consequence: A notes digest change remains a textual-change claim only.

Known limitation: Asset metadata does not establish binary safety.

Reconsideration probe: A reviewed licensing and semantic-evidence extension would require a new plan.
